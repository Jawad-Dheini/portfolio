Early Android Apps

Five small Android apps built between ages 12 and 14, while first learning to program.

Ages 12–14 Java / Android

Overview

These are the apps that mark the start of a sustained interest in building software: a calculator, a dice-rolling simulator built to play Monopoly, a button clicker, a notes app, and a Firebase-backed chat app, all written in Java for Android between ages 12 and 14.

The Apps

  • Calculator, built at 12
  • A dice-rolling simulator, built at 13, originally to play Monopoly
  • A button clicker, built at 13
  • A notes app, built at 13 and updated at 14, with custom colors, image/link attachments, and search
  • A chat app, built at 13, using Firebase Firestore and Firebase Cloud Messaging
